Manual Book & Dokumentasi API

Panduan API endpoint dan konfigurasi cetak PrinterJTM 2.0.5

ESC/POS 58mm / 80mm / 100mm Bluetooth & Wi-Fi TCP Port 9100 Token tersimpan terenkripsi Android Native

1. Pengenalan Pengaturan API

PrinterJTM dapat mencetak label, teks, gambar, dan dokumen secara manual ke printer yang terhubung ke perangkat Android. Pengaturan API pada versi ini menyimpan endpoint dan token serta menyediakan tombol untuk menguji koneksi keluar ke server Anda.

Batasan API pada versi ini
Tes Koneksi API mengirim HTTP GET ke endpoint dan menyertakan token jika tersedia. Aplikasi belum mengambil atau memproses antrean job, belum mengirim callback hasil cetak, dan belum menyediakan server HTTP/Web Print Bridge untuk request masuk. Tombol Cetak Data API saat ini hanya mencetak data contoh lokal.

2. Cara Mengisi Pengaturan API di PrinterJTM

Buka menu Pengaturan (Settings) → INTEGRASI API & WEBHOOK dan sesuaikan kolom berikut:

Kolom Pengaturan Pilihan / Contoh Penjelasan Fungsional
Mode Integrasi REST API / POS
Resi Marketplace
Web Print Bridge 		Pilihan mode untuk konfigurasi antarmuka. Pencetakan tetap dilakukan dari formulir dan dokumen di aplikasi.
Web Print Bridge: Penerimaan trigger dari browser belum tersedia pada versi ini.
URL Endpoint API https://api.example.com/health URL yang akan diuji dengan HTTP GET. Domain publik harus menggunakan HTTPS; HTTP dibatasi ke alamat privat yang diterima aplikasi.
API Key / Secret Token Token yang dibuat di aplikasi Token dikirim pada header Authorization: Bearer dan X-PrinterJTM-Key saat tes koneksi. Token disimpan menggunakan EncryptedSharedPreferences dan Android Keystore; dukungan hardware-backed bergantung pada perangkat.
Auto-Print Antrean API Switch (Aktif / Non-Aktif) Pengaturan ini belum memulai polling antrean otomatis pada versi ini.
Tes Koneksi API Tombol Klik Mengirim HTTP GET dengan timeout koneksi/respons 5 detik. Respons 2xx dianggap berhasil; respons lain ditampilkan sebagai kegagalan koneksi. Isi response belum dipakai sebagai job cetak.

3. Perilaku Tes Koneksi

Permintaan berikut menggambarkan bentuk tes koneksi. Aplikasi mengirim GET ke URL yang diisi pada Pengaturan dan menyertakan header autentikasi jika token aktif:

HTTP Headers yang Dikirimkan

GET /v1/print/jobs HTTP/1.1
Host: api.tokoanda.com
Authorization: Bearer <API_KEY_ANDA>
Accept: application/json
User-Agent: PrinterJTM-Android-Client/2.5

Untuk tes koneksi, server cukup memberikan respons HTTP 2xx. PrinterJTM saat ini tidak membaca response JSON sebagai antrean cetak dan tidak mengirim status callback.

Contoh format antrean untuk pengembangan lanjutan (belum diproses aplikasi)

{
  "status": "success",
  "has_pending_job": true,
  "job": {
    "job_id": "JOB-20261015-001",
    "print_type": "pos_receipt",
    "paper_width_mm": 58,
    "auto_cut": true,
    "data": { ... }
  }
}

Contoh callback untuk pengembangan lanjutan (belum dikirim aplikasi)

Berikut contoh rancangan payload callback; versi ini belum mengirimkannya:

POST /v1/print/jobs/JOB-20261015-001/status
Content-Type: application/json

{

5. Contoh Backend untuk Prototipe Server (Belum Terhubung ke Polling PrinterJTM)

Kode contoh server di bawah dapat digunakan untuk bereksperimen dengan endpoint dan autentikasi. Aplikasi versi ini hanya menguji koneksi, bukan meminta job dari rute tersebut.

Node.js / Express Example:

// server.js
const express = require('express');
const app = express();
app.use(express.json());

const API_KEY = "jtm_sec_secret_key_anda";

// Middleware verifikasi Bearer Token
function authMiddleware(req, res, next) {
    const auth = req.headers['authorization'];
    if (!auth || auth !== `Bearer ${API_KEY}`) {
        return res.status(401).json({ error: "Unauthorized access" });
    }
    next();
}

// Endpoint antrean cetak yang diakses PrinterJTM
app.get('/v1/print/jobs', authMiddleware, (req, res) => {
    // Ambil order pertama dari database antrean
    const pendingJob = getNextPendingPrintJob();
    if (!pendingJob) {
        return res.json({ status: "success", has_pending_job: false });
    }
    res.json({
        status: "success",
        has_pending_job: true,
        job: pendingJob
    });
});

app.listen(3000, () => console.log('Print server running on port 3000'));

PHP / Laravel Example:

<?php
// routes/api.php
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Route;

Route::get('/v1/print/jobs', function (Request $request) {
    $token = $request->bearerToken();
    if ($token !== config('services.printerjtm.key')) {
        return response()->json(['error' => 'Unauthorized'], 401);
    }

    $job = PrintQueue::where('status', 'PENDING')->first();
    if (!$job) {
        return response()->json(['status' => 'success', 'has_pending_job' => false]);
    }

    return response()->json([
        'status' => 'success',
        'has_pending_job' => true,
        'job' => $job->payload
    ]);
});

6. Pemecahan Masalah (Troubleshooting)

Gejala / Kode Kemungkinan Penyebab Solusi
HTTP 401 Unauthorized API Key pada pengaturan PrinterJTM tidak cocok dengan yang diharapkan server. Periksa kembali teks token di menu pengaturan. Pastikan tidak ada spasi tersembunyi di awal atau akhir.
HTTP 404 Not Found URL endpoint API salah atau path routing belum didaftarkan di server. Uji URL endpoint menggunakan aplikasi Postman atau browser untuk memastikan path sudah benar.
Koneksi Timeout / EHOSTUNREACH Tablet Android dan Server berada pada jaringan berbeda atau firewall memblokir port. Pastikan tablet terhubung ke Wi-Fi yang sama (jika server lokal) atau gunakan domain publik dengan HTTPS aktif.
Teks Cetak Terpotong Pengaturan lebar kertas di PrinterJTM (58mm) tidak sesuai dengan fisik printer (80mm) atau sebaliknya. Sesuaikan pilihan ukuran kertas di menu Pengaturan Printer (58mm, 80mm, atau 100mm).
