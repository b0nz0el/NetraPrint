1. Pengenalan Integrasi API & Webhook

Aplikasi PrinterJTM dirancang bukan hanya sebagai aplikasi kasir dan cetak resi manual, namun juga berfungsi sebagai Thermal Print Bridge Engine canggih untuk ekosistem bisnis Anda. Dengan fitur Integrasi API, aplikasi Anda (Website Kasir POS, ERP, E-commerce, Backend Laravel, NodeJS, Python, Go) dapat langsung memerintahkan printer thermal Bluetooth dan Wi-Fi untuk mencetak struk secara otomatis tanpa perantara komputer PC.

💡 Mengapa Menggunakan Integrasi API PrinterJTM?
Printer thermal Bluetooth dan Wi-Fi dihubungkan langsung ke tablet/HP Android Anda. Aplikasi PrinterJTM akan mengambil antrean cetak dari server Anda secara instan dan mengeksekusi perintah cetak dalam hitungan milidetik.

2. Cara Mengisi Pengaturan API di PrinterJTM

Buka menu Pengaturan (Settings) → INTEGRASI API & WEBHOOK dan sesuaikan kolom berikut:

Kolom Pengaturan Pilihan / Contoh Penjelasan Fungsional
Mode Integrasi REST API / POS
Resi Marketplace
Web Print Bridge 		REST API / POS: Untuk cetak struk kasir retail/resto.
Resi Marketplace: Format label pengiriman paket e-commerce.
Web Print Bridge: Menerima trigger cetak dari browser web via URL scheme.
URL Endpoint API https://api.tokoanda.com/v1/print/jobs Alamat endpoint server Anda yang menyediakan data antrean cetak (wajib mendukung protokol https:// atau http://).
API Key / Secret Token jtm_sec_99a8b7c6d5e4... Kunci rahasia untuk autentikasi server. Disimpan dengan enkripsi hardware AES-256 GCM di Android Keystore demi mencegah kebocoran data.
Auto-Print Antrean API Switch (Aktif / Non-Aktif) Jika diaktifkan, aplikasi akan langsung mencetak dokumen yang baru masuk tanpa membutuhkan konfirmasi klik dari kasir.
Tes Koneksi API Tombol Klik Melakukan *ping* HTTP GET ke endpoint untuk memvalidasi status respons server (HTTP 200 OK) dan mengecek kesiapan autentikasi token.

3. Panduan Teknis untuk Developer & Server Backend

Aplikasi PrinterJTM akan melakukan request HTTP ke endpoint Anda dengan header standar industri berikut:

HTTP Headers yang Dikirimkan

GET /v1/print/jobs HTTP/1.1
Host: api.tokoanda.com
Authorization: Bearer <API_KEY_ANDA>
Accept: application/json
User-Agent: PrinterJTM-Android-Client/2.5

Struktur Response JSON Standar

Server Anda harus mengembalikan response JSON dengan kode status 200 OK dengan struktur sebagai berikut:

{
  "status": "success",
  "has_pending_job": true,
  "job": {

}

Status Callback (Opsional)

Setelah pencetakan selesai, aplikasi dapat mengirimkan konfirmasi kembali ke endpoint webhook server Anda:

5. Contoh Implementasi Endpoint Backend (Node.js & PHP)

Node.js / Express Example:

// server.js
const express = require('express');
const app = express();
app.use(express.json());

const API_KEY = "jtm_sec_secret_key_anda";

// Middleware verifikasi Bearer Token
function authMiddleware(req, res, next) {
    const auth = req.headers['authorization'];
    if (!auth || auth !== `Bearer ${API_KEY}`) {
        return res.status(401).json({ error: "Unauthorized access" });
    }
    next();
}

// Endpoint antrean cetak yang diakses PrinterJTM
app.get('/v1/print/jobs', authMiddleware, (req, res) => {
    // Ambil order pertama dari database antrean
    const pendingJob = getNextPendingPrintJob();
    if (!pendingJob) {
        return res.json({ status: "success", has_pending_job: false });
    }
    res.json({
        status: "success",
        has_pending_job: true,
        job: pendingJob
    });
});

app.listen(3000, () => console.log('Print server running on port 3000'));

PHP / Laravel Example:

<?php
// routes/api.php
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Route;

Route::get('/v1/print/jobs', function (Request $request) {
    $token = $request->bearerToken();
    if ($token !== config('services.printerjtm.key')) {
        return response()->json(['error' => 'Unauthorized'], 401);
    }

    $job = PrintQueue::where('status', 'PENDING')->first();
    if (!$job) {
        return response()->json(['status' => 'success', 'has_pending_job' => false]);
    }

    return response()->json([
        'status' => 'success',
        'has_pending_job' => true,
        'job' => $job->payload
    ]);
});

6. Pemecahan Masalah (Troubleshooting)

Gejala / Kode Kemungkinan Penyebab Solusi
HTTP 401 Unauthorized API Key pada pengaturan PrinterJTM tidak cocok dengan yang diharapkan server. Periksa kembali teks token di menu pengaturan. Pastikan tidak ada spasi tersembunyi di awal atau akhir.
HTTP 404 Not Found URL endpoint API salah atau path routing belum didaftarkan di server. Uji URL endpoint menggunakan aplikasi Postman atau browser untuk memastikan path sudah benar.
Koneksi Timeout / EHOSTUNREACH Tablet Android dan Server berada pada jaringan berbeda atau firewall memblokir port. Pastikan tablet terhubung ke Wi-Fi yang sama (jika server lokal) atau gunakan domain publik dengan HTTPS aktif.
Teks Cetak Terpotong Pengaturan lebar kertas di PrinterJTM (58mm) tidak sesuai dengan fisik printer (80mm) atau sebaliknya. Sesuaikan pilihan ukuran kertas di menu Pengaturan Printer (58mm, 80mm, atau 100mm).
